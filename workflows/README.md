# GitHub Workflows

This directory contains GitHub Actions workflows for the TopoGPT3 project.

## Available Workflows

### github-actions-demo.yml

Basic GitHub Actions demonstration for the project. This workflow serves as a template and starting point for configuring CI/CD in the repository.

## Purpose

Workflows in this directory automate tasks such as:

- Running automated tests
- Code style verification (linting)
- Package building and validation
- Documentation deployment

## Viewing Workflow Status

You can view workflow status in the **Actions** tab of the repository:

[https://github.com/grisuno/TopoGPT3/actions](https://github.com/grisuno/TopoGPT3/actions)

## Adding New Workflows

To add a new workflow, create a `.yml` file in this directory following the [GitHub Actions workflow syntax](https://docs.github.com/en/actions/using-workflows/workflow-syntax-for-github-actions).
